# Installation

Install f-vueuse in your Vue project.

## Prerequisites

- Vue 3.2+
- TypeScript (optional but recommended)

## Package Managers

### npm

```bash
npm install f-vueuse
```

### yarn

```bash
yarn add f-vueuse
```

### pnpm

```bash
pnpm add f-vueuse
```

## CDN

You can also use f-vueuse via CDN:

```html
<script src="https://unpkg.com/f-vueuse"></script>
```

## Setup

In your Vue component:

```vue
<script setup>
import { useLoading, useMouse } from 'f-vueuse'

// Use composables
</script>
```

## TypeScript

f-vueuse is written in TypeScript and provides full type support. No additional setup is needed.
