useMouse ​

追踪鼠标位置。

用法 ​

vue
<script setup>
import { useMouse } from 'f-vueuse'

const { x, y } = useMouse()
</script>

<template>
  <div>
    鼠标位置: ({{ x }}, {{ y }})
  </div>
</template>

返回值 ​

参数类型描述
xRef<number>鼠标 X 坐标
yRef<number>鼠标 Y 坐标

类型定义 ​

typescript
type UseMouseReturn = {
  x: Ref<number>
  y: Ref<number>
}
