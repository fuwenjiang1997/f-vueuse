# f-vueuse

A collection of Vue composables for building powerful applications.

## Features

- 🎯 **Type Safe**: Full TypeScript support
- ⚡ **Lightweight**: Minimal bundle size
- 📦 **Tree Shakeable**: Only import what you need
- 🌐 **Internationalization**: Built-in i18n support

## Getting Started

Check out our [Guide](./guide) to get started with f-vueuse.

## Composables

- [useLoading](./useLoading) - Loading state management
- [useMouse](./useMouse) - Mouse position tracking
