# f-vueuse

一个用于构建强大应用的 Vue composables 集合。

## 特性

- 🎯 **类型安全**: 完整的 TypeScript 支持
- ⚡ **轻量级**: 最小化的包体积
- 📦 **支持 Tree Shaking**: 只导入你需要的功能
- 🌐 **国际化**: 内置 i18n 支持

## 开始使用

查看我们的 [指南](./guide) 开始使用 f-vueuse。

## Composables

- [useLoading](./useLoading) - 加载状态管理
- [useMouse](./useMouse) - 鼠标位置追踪
