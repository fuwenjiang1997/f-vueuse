# 安装

在你的 Vue 项目中安装 f-vueuse。

## 前置要求

- Vue 3.2+
- TypeScript（可选但推荐）

## 包管理器

### npm

```bash
npm install f-vueuse
```

### yarn

```bash
yarn add f-vueuse
```

### pnpm

```bash
pnpm add f-vueuse
```

## CDN

你也可以通过 CDN 使用 f-vueuse：

```html
<script src="https://unpkg.com/f-vueuse"></script>
```

## 设置

在你的 Vue 组件中：

```vue
<script setup>
import { useLoading, useMouse } from 'f-vueuse'

// 使用 composables
</script>
```

## TypeScript

f-vueuse 用 TypeScript 编写，提供完整的类型支持。无需额外设置。
